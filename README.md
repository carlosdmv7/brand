The design system behind my portfolio and its apps ("warm paper, petrol ink")
is defined once in this repo and generated into every repo that uses it, with
a CI check that fails when a repo drifts.

**Guidelines:** [BRAND.md](BRAND.md) · **Why it is a package:**
[ADR 0001](docs/adr/0001-one-package-for-the-brand.md)

## What is in it

| Module | Needs | What it gives you |
|---|---|---|
| `brand.tokens` | nothing | Every colour, font, radius and chart scale as constants |
| `brand.contrast` | nothing | WCAG ratios for every pair the brand produces |
| `brand sync` (CLI) | nothing | Writes the theme into `.streamlit/config.toml` or a stylesheet |
| `brand.altair` | `[streamlit]` | The Altair theme, enabled on import |
| `brand.streamlit` | `[streamlit]` | Byline, freshness strip, lede, footer, `altair_chart()` |

## Use it in a Streamlit app

```bash
uv add "brand[streamlit] @ git+https://github.com/carlosdmv7/brand@c3973c4a16bbbe57905ccc7d83a6cb94378b3bba"
```

In `.streamlit/config.toml`, delete the hand-written `[theme*]` tables and put
the markers where they were:

```toml
# >>> brand — generated by `brand sync streamlit`. Do not edit by hand.
# <<< brand

[server]
headless = true
```

```bash
uv run brand sync streamlit                       # fills the block
uv run brand sync streamlit --check               # in CI: exit 1 on drift
uv run brand sync streamlit --font-prefix "Twemoji Country Flags"   # extra font first
```

```python
from brand.streamlit import StripItem, altair_chart, render_footer, render_header
from brand.tokens import RUST_500, TEAL_700
```

Anything that is not a theme key goes **after** the end marker as its own
table, for example an app's `[[theme.fontFaces]]` or `[server]`.

An app whose charts need that extra family too re-registers the chart theme
once, at import:

```python
import brand.altair

brand.altair.register(font_prefix=["Twemoji Country Flags"])
```

## Use it in the portfolio (no Python project needed)

Wrap the token block of `styles.css` in
`/* >>> brand ... */` … `/* <<< brand */`, then:

```bash
uvx --from git+https://github.com/carlosdmv7/brand@c3973c4a16bbbe57905ccc7d83a6cb94378b3bba brand sync css styles.css
```

Site-only tokens (shadows, focus ring) stay in a second `:root` outside the
markers.

## Changing the brand

1. Edit `src/brand/tokens.py`, then `BRAND.md` if a rule changed.
2. `make check`. The contrast tests fail if the change breaks AA.
3. Bump `version` and merge to `main`.
4. In each consumer: move the pinned commit, run `brand sync`, and commit.
   Pin a commit SHA in the PEP 508 form (`brand @ git+…@<sha>`) rather than
   `[tool.uv.sources]`. A plain pip install, like Streamlit Community Cloud's,
   then resolves the same commit and never a same-named PyPI package.

## Development

```bash
make install   # uv sync
make check     # lint + format check + tests — the same gate CI runs
make contrast  # the full contrast table
```
